1. Sets and Set Operations

1.1 Set kya hota hai?

Set ek well-defined collection of distinct objects ka group hota hai.

Simple language mein: agar hum kuch objects/items ko ek group mein rakhte hain aur clearly pata hai ki kaunsa object group ka member hai aur kaunsa nahi, to us group ko Set kehte hain.

Example:

A = {1, 2, 3, 4, 5}

Yeh ek set hai jisme 1,2,3,4,5 elements hain.

1.2 Elements

Set ke andar jo individual objects hote hain unhe elements kehte hain.

A = {10, 20, 30}

Yahan 10, 20 aur 30 elements hain.

Notation:

  • 10 ∈ A → 10 set A ka element hai.
  • 50 ∉ A → 50 set A ka element nahi hai.

1.3 Set ko represent kaise karte hain?

Method 1: Roster / Listing Method

Saare elements directly likh dete hain.

A = {2, 4, 6, 8, 10}

Method 2: Set Builder Method

Elements ki property batate hain.

A = {x | x is an even number and x ≤ 10}

Iska meaning hai: "Saare x jinke liye x even hai aur 10 se chhota ya equal hai."

1.4 Important Types of Sets

Type Meaning Example
Empty Set Jisme koi element nahi ∅
Singleton Set Sirf ek element {5}
Finite Set Limited elements {1,2,3}
Infinite Set Unlimited elements {1,2,3,4,...}
Universal Set Problem ke saare possible elements U

1.5 Cardinality

Set mein total kitne elements hain, usko cardinality kehte hain.

A = {2,4,6,8}

|A| = 4

1.6 Subset

A agar B ke saare elements contain karta hai, to A ko B ka subset kehte hain.

Notation:

A ⊆ B

A = {1,2}

B = {1,2,3,4}

A ke saare elements B ke andar hain.

Therefore:

A ⊆ B

1.7 Proper Subset

A subset hai B ka aur A ≠ B, to A proper subset hai.

A ⊂ B

1.8 Union

Union ka matlab: dono sets ke saare unique elements ko combine karna.
A ∪ B
A = {1,2,3}
B = {3,4,5}

A ∪ B = {1,2,3,4,5}

Notice karo 3 ko do baar nahi likha because set mein duplicate elements nahi hote.

1.9 Intersection

Intersection mein sirf common elements aate hain.
A ∩ B
A = {1,2,3}
B = {3,4,5}

A ∩ B = {3}

1.10 Difference

A - B ka matlab: A ke elements jo B mein nahi hain.

A = {1,2,3,4}
B = {3,4,5,6}

A - B = {1,2}

1.11 Complement

Universal set U ke andar jo elements A mein nahi hain, woh A ka complement hain.

A' = U - A
U = {1,2,3,4,5}
A = {1,2}

A' = {3,4,5}

1.12 Power Set

Power set kisi set ke saare possible subsets ka set hota hai.
A = {1,2}

P(A) = {∅, {1}, {2}, {1,2}}

Total subsets = 2n

Agar set mein n elements hain to total subsets:

Number of subsets = 2n

Example: A mein 3 elements hain.

23 = 8 subsets.

1.13 Cartesian Product

Do sets ke elements ke ordered pairs banane ko Cartesian Product kehte hain.
A × B = {(a,b) | a ∈ A and b ∈ B}
A = {1,2}
B = {a,b}

A × B = {(1,a),(1,b),(2,a),(2,b)}

Agar |A| = m aur |B| = n:

|A × B| = m × n

1.14 Computing mein Sets ka use

  • Database mein records ko group karna
  • Programming mein collections
  • Search results
  • Database queries
  • AI aur Machine Learning mein data categories
  • Probability
  • Logic

  • Network users/devices ko represent karna
Real Computing Example:

Suppose ek college mein:

Java students = {A, B, C, D}

Python students = {C, D, E, F}

Java ∩ Python = {C,D}

Matlab C aur D dono Java aur Python padh rahe hain.

2. Functions

2.1 Function kya hota hai?

Function ek rule/mapping hai jo har input ko exactly ek output se associate karta hai.

Simple language:

Input → Function → Output

Agar: f(x) = 2x + 3

Input x = 5
f(5) = 2(5) + 3
f(5) = 13

2.2 Function ka basic structure

f : A → B

Iska matlab: Function f set A ke elements ko set B ke elements mein map karta hai.

A = Domain

B = Codomain

2.3 Domain

Function ko diye ja sakne wale valid inputs ka set Domain hota hai.
f(x) = x + 5

Agar x koi bhi real number ho sakta hai, to domain = all real numbers.

2.4 Codomain

Possible outputs ka declared set codomain hota hai.

2.5 Range

Actually function se jo outputs generate hote hain, unka set Range kehlata hai.
f(x) = x²

Domain = Real numbers
Outputs = 0,1,4,9,...

Range = y ≥ 0

2.6 One-to-One Function

Different inputs ke outputs bhi different hon, to function one-to-one hai.
f(x) = 2x

f(1)=2
f(2)=4
f(3)=6

Har input ka unique output hai.

2.7 Many-to-One Function

f(x)=x²

f(2)=4
f(-2)=4

Different inputs ka same output.

2.8 Onto Function

Agar codomain ka har element kisi na kisi input se map ho raha hai, to function onto hai.

2.9 Into Function

Agar codomain ke kuch elements unused reh jaate hain, to function into hai.

2.10 Bijective Function

Jo function both one-to-one aur onto ho, use bijective function kehte hain.

Bijective function ka special benefit:

Bijective function ka inverse function exist karta hai.

2.11 Computing mein Functions

Programming mein function ka concept bahut important hai. 

function add(a, b):
    return a + b

Yahan:

  • a,b = inputs
  • add() = function
  • a+b = output
Mathematics:
f(x) = x²

Programming: 
square(x):
    return x*x

Concept same hai: input → operation → output

3. Graphs

3.1 Graph kya hota hai?

Graph vertices (nodes) aur edges (connections) ka structure hota hai.

Graph ko generally:

G = (V,E)

se represent karte hain.

  • V = Vertices / Nodes
  • E = Edges / Connections

3.2 Real-life Example

Suppose 4 cities hain:

A, B, C, D

Aur roads:

  • A-B
  • B-C
  • C-D
  • A-D

Cities = vertices

Roads = edges

3.3 Undirected Graph

Edge ki direction nahi hoti.

A — B

Matlab A se B aur B se A connection same hai.

3.4 Directed Graph

Edges ki direction hoti hai.

A → B

Matlab A se B connection hai, zaroori nahi B se A bhi ho.

3.5 Weighted Graph

Edges ke saath weight/cost/distance diya hota hai.

A ---- 10 ---- B

10 distance/cost/time represent kar sakta hai.

3.6 Degree of Vertex

Kisi vertex se connected edges ki count ko degree kehte hain.

A ke saath 3 edges connected hain.

Degree(A) = 3

3.7 Path

Graph mein ek vertex se doosre vertex tak jaane ka route path hota hai.

A → B → C → D

3.8 Cycle

Aisa path jo start vertex par wapas aa jaye, cycle kehlata hai.

A → B → C → A

3.9 Tree

Tree ek connected graph hota hai jisme cycle nahi hoti.

Agar tree mein n vertices hain:

Number of edges = n - 1

  • Google Maps

  • Internet routing

  • Artificial Intelligence
  • Recommendation systems
  • Web page linking
Facebook/Instagram type example:

Person = Node

4. Mathematical Modelling

4.1 Mathematical Modelling kya hai?

Real-world problem ko mathematical equations, functions, graphs ya formulas ke form mein represent karna mathematical modelling hai.

Simple flow:

Real World Problem → Mathematical Model → Calculation → Result → Real World Decision

4.2 Example: Mobile Data Usage

Suppose ek student daily 2 GB data use karta hai.

To n days ke liye data usage:

D(n) = 2n

Agar 7 days hain:

D(7) = 2 × 7 = 14 GB

4.3 Modelling ke Steps

  1. Problem ko understand karo.
  2. Important variables identify karo.
  3. Assumptions banao.
  4. Mathematical equation/model banao.
  5. Model ko solve karo.
  6. Result ko real-world situation se compare karo.
  7. Zarurat ho to model improve karo.

4.4 Variables

Variable ek quantity hai jiska value change ho sakta hai.

Suppose:

x = number of students
y = total books

Agar har student ko 3 books chahiye:
y = 3x

4.5 Computing Example: Algorithm Time

Suppose ek algorithm n items ko check karta hai aur har item ko ek baar process karta hai.

Approximate operations:

T(n) = n

Isko computer science mein:

O(n)

kehte hain.

Agar n double hota hai, approximately operations bhi double ho jaate hain.

4.6 Example: Binary Search

Binary search mein sorted data ko repeatedly half kiya jaata hai.

Number of steps approximately:

log₂(n)

For example:

n = 1024

log₂(1024) = 10

Matlab approximately 10 divisions mein search complete ho sakti hai.

5. Sequences

5.1 Sequence kya hoti hai?

Numbers ka ek ordered list sequence kehlata hai.
2, 4, 6, 8, 10, ...

Order important hai.

5.2 Sequence notation

Sequence ko generally:

a₁, a₂, a₃, a₄, ...

likhte hain.

a₁ = first term

a₂ = second term

aₙ = nth term

5.3 Arithmetic Sequence

Jisme consecutive terms ka difference same hota hai, woh Arithmetic Sequence hai.
2, 5, 8, 11, 14, ...

Difference: 5-2 = 3
8-5 = 3
11-8 = 3

Common difference = d

Formula

aₙ = a₁ + (n-1)d

5.4 Arithmetic Sequence Example

Sequence:

3, 7, 11, 15, ...

Here:

  • a₁ = 3
  • d = 4

Find 10th term:

a₁₀ = 3 + (10-1)(4)
a₁₀ = 3 + 36 = 39

5.5 Geometric Sequence

Jisme consecutive terms ka ratio same hota hai, woh Geometric Sequence hai.
2, 6, 18, 54, ...

6/2 = 3
18/6 = 3
54/18 = 3

Common ratio = 3

Formula

aₙ = a₁ × rn-1

5.6 Geometric Sequence Example

2, 4, 8, 16, ...

a₁ = 2

r = 2

5th term:

a₅ = 2 × 24
a₅ = 32

5.7 Fibonacci Sequence

Fibonacci sequence mein next term previous two terms ka sum hota hai.
0, 1, 1, 2, 3, 5, 8, 13, 21, ...

Rule:

F(n) = F(n-1) + F(n-2)

5.8 Computing mein Fibonacci

Fibonacci recursion samajhne ke liye famous example hai. 

fib(n):
    if n <= 1:
        return n

    return fib(n-1) + fib(n-2)

Isse recursion aur algorithm complexity samajhne mein help milti hai.

6. Series

6.1 Series kya hoti hai?

Sequence ke terms ko add karne par Series milti hai.
Sequence: 1, 2, 3, 4, 5

Series: 1 + 2 + 3 + 4 + 5

6.2 Arithmetic Series

Arithmetic sequence ke terms ka sum Arithmetic Series hota hai.

Formula

Sₙ = n/2 × [2a + (n-1)d]

Alternative formula:

Sₙ = n/2 × (a + l)

where:

  • a = first term
  • l = last term
  • n = number of terms

6.3 Example

Find sum:

2 + 4 + 6 + 8 + 10

Here:

  • a = 2
  • l = 10
  • n = 5
S = 5/2 × (2+10)
S = 30

6.4 Geometric Series

Geometric sequence ke terms ko add karne par Geometric Series milti hai.

2 + 4 + 8 + 16 + ...

Finite Geometric Series Formula

Sₙ = a(rn-1)/(r-1)

Equivalent form:

Sₙ = a(1-rn)/(1-r)

6.5 Infinite Geometric Series

Agar |r| < 1 ho, to infinite geometric series ka sum finite value par approach karta hai.

S∞ = a/(1-r)
1 + 1/2 + 1/4 + 1/8 + ...

a = 1
r = 1/2

S∞ = 1/(1-1/2)
S∞ = 2

6.6 Series ka Computing mein use

  • Algorithm complexity
  • Probability calculations
  • Approximation algorithms
  • Numerical methods
  • Signal processing
  • Computer graphics
  • Machine learning

6.7 Algorithm Example

Suppose nested operations ki count approximately:

1 + 2 + 3 + ... + n

Iska sum:

n(n+1)/2

Ye approximately:

O(n²)

ko explain karne mein help karta hai.

7. Applications in Computing

Ab sab concepts ko computer science se connect karte hain.

7.1 Sets → Databases

Database mein different categories ko sets ke form mein samajh sakte hain.

Students who know Java: A = {Rahul, Aman, Priya}

Students who know Python: B = {Priya, Aman, Neha}

A ∩ B = {Rahul?}

Actually correct intersection:

A ∩ B = {Aman, Priya}

Matlab Aman aur Priya dono Java aur Python jaante hain.

7.2 Sets → SQL

Database operations ka set theory se strong connection hai.

  • UNION → UNION
  • Common records → INTERSECTION concept
  • Difference → EXCEPT / MINUS concept

7.3 Functions → Programming

Programming function basically mathematical function ke concept se related hai. 

def multiply(a, b):
    return a * b

Input:

a=5, b=4

Output:

20

7.4 Functions → Machine Learning

Machine learning mein model input data ko output/prediction mein map karta hai.

Input → Model Function → Prediction

Example:

Input: House size = 1200 sq ft

Function/model: Price = f(size)

Output: Predicted house price

7.5 Graphs → Computer Networks

Computer network ko graph ke form mein represent kar sakte hain.

  • Computer/Router = Node
  • Network connection = Edge

7.6 Graphs → Google Maps

Map ko graph ki tarah imagine karo.

  • Road = Edge

Shortest path algorithms jaise Dijkstra ka use karke shortest route find kiya ja sakta hai.

7.7 Graphs → Social Media

Social media mein:

Is graph se friends-of-friends, communities aur recommendations jaise problems solve ki ja sakti hain.

7.8 Sequences → Time Series

Stock price, temperature, CPU usage etc. time ke according values ki sequence ho sakti hai.

CPU Usage: 20%, 25%, 31%, 28%, 35%, ...

Ye ek time-based sequence hai.

7.9 Series → Algorithm Analysis

Algorithm ke operations ko add karne ke liye series ka use hota hai.

1 + 2 + 3 + ... + n

8. Important Differences

Sequence vs Series

Sequence Series
Ordered list of numbers Sequence ke terms ka sum
2,4,6,8 2+4+6+8
Order important Terms add hote hain

Domain vs Codomain vs Range

Term Meaning
Domain Possible inputs
Codomain Declared possible outputs
Range Actually generated outputs

Union vs Intersection

Operation Meaning
A ∪ B Dono sets ke unique elements
A ∩ B Sirf common elements

Arithmetic vs Geometric Sequence

Arithmetic Geometric
Constant difference Constant ratio
2,4,6,8 2,4,8,16
d = 2 r = 2
